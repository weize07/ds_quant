# 中粮糖业（600737）糖周期监控系统

针对 25% 仓位的中粮糖业持仓，每天自动抓取**郑糖主力、ICE 原糖、股价、厄尔尼诺(ONI)**，计算**糖周期反转概率**并输出可执行的加减仓信号卡。

> 当前信号（2026-08-21）：**反转概率 61.1% → 🟡 持有观察区**
> 核心逻辑：厄尔尼诺已确认（ONI +1.39）但国际糖价（ICE）尚未共振，等待郑糖突破 5688 确认或跌破 5053 证伪。

## 四、Windows 定时任务（自动每日运行）

A股收盘 15:00，建议 **15:30** 跑一次（此时郑糖日线、股价日线都已更新）。用管理员 PowerShell 创建：

```powershell
schtasks /Create /TN "中粮糖业每日监控" `
  /TR "cmd /c cd /d C:\Users\zewei\workspace\ds_quant && node monitor.js >> logs\monitor.log 2>&1" `
  /SC DAILY /ST 15:30 /F
```

参数说明：
- `/SC DAILY /ST 15:30`：每天 15:30 触发
- `>> logs\monitor.log 2>&1`：把运行日志写入 `logs\monitor.log`（便于排查）
- 先手动建 `logs` 目录：`New-Item -ItemType Directory -Force C:\Users\zewei\workspace\ds_quant\logs`

**管理定时任务**：
```powershell
schtasks /Query /TN "中粮糖业每日监控"        # 查看
schtasks /Delete /TN "中粮糖业每日监控" /F    # 删除
schtasks /Run /TN "中粮糖业每日监控"           # 立即触发一次
```

> 如果定时任务里 Node 找不到，用 `where.exe node` 查到完整路径后替换命令里的 `node` 为绝对路径。

## 五、打分模型说明

**反转概率 = 各维度确认度加权 + 价格确认门控**

| 维度 | 权重 | 说明 |
|------|------|------|
| 厄尔尼诺 ENSO | 20% | 领先信号，ONI≥+1.0 强厄尔尼诺给 80 分（传导到减产仍有不确定性，封顶） |
| 郑糖趋势 | 30% | 国内糖价，主锚。MA20/MA60/动量 + 是否突破确认位 5688 |
| 内外价差/进口利润 | 15% | 配额外进口利润率。**倒挂(负)=进口断供利多内盘；正利润=进口冲击压制内盘**，这是"外强内弱"的直接度量 |
| 股价趋势 | 20% | 600737 技术面，含"单日大跌惩罚"（防投机急拉急跌） |
| 位置(历史分位) | 15% | 郑糖 20 年分位，越低越便宜、上行空间越大 |

**价格确认门控**（核心防虚高）：
- 郑糖**突破 5688**（1年高点）→ 反转概率保底 72%，直接进加仓区
- 郑糖**跌破 5053**（1年低点）→ 反转概率封顶 40%，直接进减仓区
- 两者之间 → 按加权分，落在"持有观察区"

**信号区间**：
| 反转概率 | 信号 | 动作 |
|----------|------|------|
| ≥ 70% | 🟢 加仓区 | 趋势确认，可择机加仓 |
| 45~70% | 🟡 持有观察区 | 持有，等突破/跌破确认 |
| < 45% | 🟠 减仓区 | 逢反弹减仓 |
| 触发止损线 | 🔴 清仓 | 无条件执行风控 |

## 七、数据源清单与已知问题

| 数据 | 来源 | 接口 | 可靠性 |
|------|------|------|--------|
| 600737 日K | 东方财富 | push2his.eastmoney.com | ⚠️ 会限流 |
| 郑糖主力 SR0 | 新浪财经 | stock2.finance.sina.com.cn | ✅ 稳定（2006至今） |
| ICE 原糖 | 东方财富全球期货 | 历史 `108.SB26V`；实时 `108.SB00Y`(push2) 兜底 | ⚠️ 会限流，已加实时兜底 |
| 汇率 USD/CNY | 新浪财经 | hq.sinajs.cn `fx_susdcny`（需 Referer） | ✅ 稳定 |
| ONI 厄尔尼诺 | NOAA CPC | cpc.ncep.noaa.gov | ✅ 稳定 |

### 进口利润计算公式（估算）

```
原糖折人民币 = ICE原糖(美分/磅) × 22.0462 × 汇率(USD/CNY)     # 元/吨
配额外进口成本 = 原糖折人民币 × 1.5(50%关税) ÷ 0.92(出糖率) + 550(加工费+运费)
进口利润率 = (郑糖 - 配额外进口成本) / 配额外进口成本
```

- **进口利润率 > 0**：配额外进口有利可图 → 进口糖冲击 → **压制国内糖价**（内弱）
- **进口利润率 < 0（倒挂）**：进口断供 → 国内供应收紧 → **利多国内糖价**（内盘补涨动力）
- 这就是"外强内弱"的量化：外盘（ICE）涨→进口成本升→利润率收窄→倒挂→内盘被动补涨

> ⚠️ 公式为**估算值**，未含增值税、升贴水，精确值以[沐甜科技](https://msweet.com.cn)每日"进口糖升贴水、运费及加工成本"为准。加工费/运费在 `monitor.js` 顶部 `CONFIG.importFee` 可调。

**限流说明**：东财接口对**高频请求**会返回空响应/断连（`socket hang up`）。脚本已内置：
1. 自动重试（3 次，间隔 1.5s）
2. 失败自动回退本地缓存
3. 无缓存时按"数据缺失"处理（ICE 缺失按中性 50 分计，不污染结果）

日常每天 1 次定时任务**不会触发限流**；只有短时间内反复调试才会。若调试时遇到 ICE/600737 抓取失败，等 15~30 分钟再跑即可。

## 八、信号卡解读

每天盘后打开 `reports\YYYY-MM-DD.md`，重点看三处：

1. **结论区**：反转概率 + 信号 + 建议动作
2. **打分明细**：五个维度哪个强哪个弱——尤其注意"ICE 与郑糖是否共振"。若郑糖涨而 ICE 弱（当前就如此），说明是"内强外弱"的进口预期行情，持续性存疑
3. **关键阈值监控**：郑糖距 5688 还有多少、股价距清仓线还有多少

**执行纪律**（最重要）：
- 信号是**辅助**，风控是**铁律**。跌破清仓线 12.24 必须执行，不因任何信号犹豫。
- "持有观察区"就是**不动**，不要因为厄尔尼诺的消息追高，等价格自己给出确认。

7. **相关性随时间变化**（12 个月滚动相关系数）
8. **相关性结论表**

### 当前相关性关键结论

| 关系 | 相关系数 | 含义 |
|------|----------|------|
| 郑糖 ↔ 股价（近3年） | **-0.82（强负相关）** | ⚠️ 股价与糖价脱钩：糖价跌 17% 而股价涨 165%，主要由公司故事（2025年8月单周+65%跳涨）驱动 |
| ONI → 郑糖（领先12个月） | +0.26（弱正相关） | 厄尔尼诺→减产→糖价上涨的传导约需 12 个月，但相关性偏弱 |

> **重要提醒**：`郑糖↔股价 -0.82` 这个负相关说明，近 3 年买中粮糖业**不是**在买糖价 beta，而是在买公司本身的"业绩韧性/拐点预期"故事。所以反转概率模型里"股价趋势"和"郑糖趋势"是**两个独立维度**，不能互相替代。
